# Silora Europe Sprint

A two-week coached learning project combining:

- European B2B market development
- Figma marketing-page design
- HTML, CSS, and JavaScript
- Codex planning, implementation, review, and reflection

The fictional brand **Silora Works** demonstrates an ODM/OEM silicone food
storage collection. It is intentionally fictional: certifications, capacities,
customers, and performance claims are placeholders until verified.

## Start

```bash
npm run typecheck
npm test
npm run build
npm run dev
```

Open:

- Factory homepage: `http://localhost:4173/site/`
- Product landing page: `http://localhost:4173/site/product.html`

## Publishing

This is a static website. Publish the contents of `dist/` using GitHub Pages,
Netlify, Cloudflare Pages, or an equivalent static host after replacing all
fictional claims and contact details. No deployment credentials are configured
in this workspace, so public publishing is intentionally not automated.
