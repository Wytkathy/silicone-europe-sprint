# DAY 1｜制造工厂的市场分析入门课

## 学习目标

完成本课程后，你应该能够：

- 用自己的话解释市场分析是什么，以及它为什么不是“搜集行业资料”。
- 解释生产型制造工厂做市场分析的特殊目的。
- 区分市场、客户、竞争、产品和工厂能力五类分析对象。
- 设计一套从市场假设到客户开发、产品验证和商业决策的流程。
- 理解 AI 相比传统市场分析提高了什么，以及没有改变什么。
- 判断 ODM/OEM 工厂是否适合通过短视频和投流开展小规模 OBM 实验。

> 核心认知：市场分析不是为了证明自己的想法正确，而是为了使用较低成本，尽早发现自己的想法可能错误。

## 1. 市场分析是什么？

市场分析是系统地研究市场、客户、竞争方案、产品机会和自身能力，从而减少商业决策不确定性的过程。

市场分析最终不应该只产生一份报告，而应该产生：

1. 一个清晰、可以被验证的商业假设。
2. 一组支持或反对该假设的证据。
3. 下一步最低成本的验证行动。
4. 明确的继续、修改、暂停或放弃条件。

### 五个分析对象

| 分析对象 | 核心问题 | 常见证据 |
|---|---|---|
| 市场 | 需求是否存在？是否增长？ | 行业报告、进口数据、搜索趋势、渠道变化 |
| 客户 | 谁会购买？为什么购买？ | 客户官网、访谈、邮件回复、采购要求 |
| 竞争与替代 | 客户现在如何解决问题？ | 竞品、价格、评论、替代材料、用户习惯 |
| 产品 | 什么功能、定位和价格有机会？ | 差评、概念测试、落地页、样品反馈 |
| 工厂能力 | 我们能否稳定、合规、盈利地交付？ | 成本、MOQ、交期、良率、检测和质量记录 |

### 事实、信号与假设

| 类型 | 含义 | 示例 |
|---|---|---|
| 事实 | 能由可靠来源直接证明 | 某品牌官网销售厨房收纳产品 |
| 信号 | 事实可能暗示某种商业方向 | 该品牌强调颜色和产品设计 |
| 假设 | 根据事实与信号提出的待验证机会 | 该品牌可能适合颜色协调的硅胶收纳系列 |

不能把假设表达成事实。除非客户明确确认，否则不能说“该客户正在寻找供应商”。

## 2. 市场分析的目的是什么？

市场分析的本质是控制风险、提高资源配置效率。

假设开发一款新产品需要投入模具、认证、库存、包装、网站和广告。如果没有提前验证，工厂可能在大量投入后才发现：

- 消费者并不需要这个功能。
- 目标售价无法覆盖成本与渠道利润。
- 广告获客成本超过产品贡献利润。
- 产品宣传或材料不符合目标市场要求。
- 买家的 MOQ、交期和质量要求与工厂不匹配。
- 产品虽然有观看量，却没有购买意愿。

因此，市场分析需要回答：

- 什么机会值得投入？
- 投入顺序是什么？
- 最危险的未知因素是什么？
- 如何以最低成本验证？
- 出现什么结果时应该停止投入？

## 3. 制造工厂做市场分析的特殊目的

制造工厂很容易从“我们能生产什么”出发，而不是从“客户需要解决什么问题”出发。

### 两种经营逻辑

| 生产导向 | 市场导向 |
|---|---|
| 展示设备、面积和产能 | 展示能够解决的客户问题 |
| 等待客户提供设计 | 主动提出产品概念和验证方案 |
| 销售单个产品 | 帮助客户规划产品系列 |
| 主要通过价格竞争 | 竞争设计、响应、证据和服务 |
| 客户询价后才行动 | 主动研究机会并选择客户 |

### 对 ODM/OEM 工厂的具体价值

1. **选择正确客户。** 不再把所有进口商、零售商和品牌视为同样重要。
2. **提升 ODM 价值。** 从执行图纸升级为参与产品定义、系列设计和验证。
3. **减少低质量询盘。** 通过定位和内容提前筛选适合的客户。
4. **指导能力建设。** 判断应优先投资哪些工艺、检测、设计或销售能力。
5. **降低开模和库存风险。** 先验证需求，再增加不可逆投入。
6. **为 OBM 提供依据。** 判断哪些产品值得用自有品牌直接面向消费者。

### OEM、ODM 与 OBM

| 模式 | 谁定义产品与品牌？ | 工厂主要价值 | 主要风险 |
|---|---|---|---|
| OEM | 客户 | 稳定、成本、交付 | 价格竞争、客户集中 |
| ODM | 工厂与客户共同参与 | 产品开发、设计、验证 | 开发成本、知识产权、需求误判 |
| OBM | 工厂拥有品牌 | 产品、品牌、渠道和用户关系 | 库存、投流、合规、客服和现金流 |

越接近 OBM，潜在利润和市场控制力越高，但风险也明显增加。

## 4. 结合当前德国硅胶厨房用品假设

当前项目提出的训练假设是：

> 德国设计型厨房用品品牌、可持续家居零售商和具备自有品牌能力的零售商，可能需要具有差异化颜色、造型和包装的可重复使用硅胶食品收纳系列。

### 为什么选择厨房食品收纳？

- 容易通过形状、颜色、尺寸和包装进行差异化。
- 可以开发多个 SKU，形成完整产品系列。
- 品牌商和零售商均可能成为客户。
- 适合通过网页、Figma、渲染图和短视频展示。
- 相比母婴用品，初始合规风险相对更适合作为训练起点。

这不代表厨房用品一定最赚钱。它只是当前最适合同时训练市场研究、客户开发、设计表达和网页开发的方向。

### 为什么选择德国？

- 德国拥有较多厨房、家居、设计和可持续消费相关品牌与渠道。
- 技术资料、可信度和证据式沟通可能有价值。
- 许多目标客户公开展示产品类别和品牌定位，便于桌面研究。

上述内容仍然只是工作假设。正式投入前，需要通过贸易数据、竞品价格、法规调查、客户访谈和实际回复率验证。

### 当前理想客户画像

- 位于德国或邻近欧洲市场。
- 销售厨房、家居整理、可重复使用或设计型消费产品。
- 具备产品开发、外部采购、自有品牌或批发能力。
- 通过颜色、造型、包装和使用体验建立差异。
- 有能力经营多个 SKU，而不是只采购单一标准品。

## 5. 一套完整的市场分析流程

### 第一步：定义决策问题

问题必须足够具体。

错误示例：

```text
欧洲硅胶市场怎么样？
```

正确示例：

```text
德国设计型厨房品牌是否值得作为可重复使用硅胶食品收纳系列的首批目标客户？
```

### 第二步：定义用户与使用场景

研究：

- 谁是最终使用者？
- 在什么情况下使用？
- 当前如何解决问题？
- 当前方案有什么不便？
- 为什么愿意更换？
- 谁是付钱的人？谁影响购买？

### 第三步：判断市场吸引力

收集：

- 市场规模与增长信号
- 搜索和内容趋势
- 零售商产品数量
- 产品价格区间
- 消费者评价
- 法规、渠道和社会趋势

不要沉迷巨大 TAM。初学阶段更重要的是判断是否存在能够触达、能够盈利的客户。

### 第四步：分析竞争和替代方案

竞争对手不只是其他硅胶工厂，还包括玻璃盒、塑料盒、一次性袋、蜂蜡布，以及消费者选择不购买。

竞品分析至少记录：

- 售价和促销方式
- 尺寸、材料和产品组合
- 核心卖点和品牌定位
- 用户好评与差评
- 销售渠道和内容表达
- 尚未解决的问题

### 第五步：分析工厂能力

市场存在需求，不代表机会适合本工厂。

必须核验：

- 材料与生产工艺
- 模具和开发成本
- MOQ 与交期
- 良率和质量稳定性
- 检测、法规和追溯能力
- 包装和物流能力
- 报价与目标毛利

### 第六步：形成价值主张

低质量价值主张：

```text
我们是专业硅胶工厂，质量好，价格低。
```

更具体的价值主张：

```text
帮助设计型厨房品牌，把颜色、造型和包装统一为一个可扩展的硅胶食品收纳系列，并在开发过程中明确记录测试要求和修改决策。
```

### 第七步：进行低成本验证

在大量开模、生产或投流前，可以先做：

- Figma 产品概念图或 3D 渲染
- 产品落地页
- 一页产品概念说明
- 小规模客户开发信
- 买家访谈
- 短视频内容测试
- 小预算广告点击测试
- 样品测试或意向收集

### 第八步：根据证据决策

分析结果只能导向四种决策：

1. 继续投入。
2. 修改产品、客户或定位。
3. 暂停并等待更多证据。
4. 放弃方向。

放弃一个被证明不适合的方向，也是一项成功的市场分析成果。

## 6. 客户开发不是批量发送开发信

客户开发的目的是持续验证：

- 目标客户是否选对？
- 客户是否真的存在这个问题？
- 方案是否有价值？
- 客户愿意为哪些价值付钱？
- 什么证据能够建立信任？

### B2B 客户开发漏斗

```text
建立理想客户画像
→ 收集目标公司
→ 评分排序
→ 深度研究
→ 找到合适角色
→ 个性化联系
→ 需求访谈
→ 概念或样品
→ 报价与试单
→ 长期合作
```

### 高质量个性化联系结构

1. 一个经过验证的客户事实。
2. 一个明确标注的合作假设。
3. 一个有价值的想法或问题。
4. 一个低压力的下一步。

不同角色关注不同问题：

| 角色 | 关注重点 | 沟通重点 |
|---|---|---|
| 品类采购 | 利润、供货、产品线适配 | 商业结构、系列组合、风险 |
| 产品开发 | 可行性、测试、迭代 | 需求、样品、修改记录 |
| 品牌负责人 | 差异化、一致性 | 颜色、造型、包装和故事 |
| 质量与合规 | 证据、追溯、风险 | 报告、材料、变更控制 |

## 7. AI 时代与传统做法有何不同？

### AI 显著提高效率的地方

| 传统工作 | AI 辅助工作 |
|---|---|
| 人工逐个浏览客户网站 | 提取、整理并初步分类 |
| 手工制作客户表 | 按评分规则生成结构化表格 |
| 人工阅读大量竞品评论 | 聚类痛点、动机和高频问题 |
| 每封开发信从零撰写 | 根据客户证据生成个性化草稿 |
| 分析报告数周更新一次 | 每日或每周更新假设和证据 |
| 依赖个人经验 | 将成熟流程固化为 Skill |
| 分析与执行分离 | 同时制作研究表、网页、概念和邮件 |

### AI 没有改变的原则

AI 可以提高研究速度，但不能自动把推测变成事实。

大模型可能：

- 编造市场规模、客户需求或来源。
- 使用过时信息。
- 把相关性错误解释为因果关系。
- 生成语言专业但内容空洞的结论。
- 忽略工厂实际能力和目标市场法规。

必须坚持：

```text
AI 生成初步结论
→ 保留来源
→ 人工核验
→ 与客户验证
→ 根据真实结果更新
```

## 8. 如何把 AI 和 Skill 融入日常工作？

Skill 是一套可以重复调用的 AI 工作流程。它可以包含工作步骤、公司规则、参考资料、输出模板和脚本。

### 建议的 AI 市场开发工作流

```text
监测目标客户与竞品
→ 提取产品、价格和新动态
→ 更新客户评分
→ 生成待人工复核的机会提示
→ 准备个性化开发信草稿
→ 记录客户反馈
→ 总结新发现并更新假设
```

### 推荐逐步建立的 Skills

| Skill | 输入 | 输出 |
|---|---|---|
| market-research | 国家、品类、产品假设 | 市场证据、风险和验证计划 |
| account-research | 客户官网 | 事实、信号、机会假设和来源 |
| competitor-review-miner | 竞品评论 | 用户痛点、频率和产品机会 |
| outreach-drafter | 客户档案、工厂能力 | 个性化开发信草稿 |
| claim-risk-reviewer | 网页、邮件、产品文案 | 未验证声明和风险提示 |
| weekly-sales-review | CRM 或客户表 | 本周机会、问题和下一步 |
| product-concept-brief | 用户问题、市场证据 | 产品概念、验证问题和设计要求 |

不要一开始建立大量 Skill。先由人工执行流程三到五次，确认流程有效，再将重复步骤固化。

### Skill 应强制执行的证据规则

- 优先使用客户官方网站和权威来源。
- 每条重要事实附带来源。
- 事实、信号和假设分别输出。
- 不猜测采购需求、联系人或竞争供应商。
- 输出最值得验证的问题。
- 对任何对外内容进行声明风险检查。

## 9. 短视频时代，工厂能否开展 OBM？

可以，但会生产不等于会经营消费品牌。

短视频降低了触达消费者和测试创意的成本，但没有消除产品、利润、合规、库存、客服和现金流风险。

### OBM 的基本利润公式

```text
单笔贡献利润
= 售价
- 产品成本
- 包装成本
- 仓储与物流
- 平台和支付费用
- 退款与售后
- 广告获客成本
```

只有贡献利润长期为正，投流才可能扩大业务。观看量高不等于能够赚钱。

### 推荐的小实验 OBM 路线

```text
发现消费者痛点
→ 制作概念图或样品
→ 发布多种短视频测试内容
→ 建立落地页收集意向
→ 小预算广告测试
→ 小批量生产
→ 验证购买、退货、复购和利润
→ 再决定是否扩大投放
```

### 短视频可以测试的内容角度

- 痛点演示：现有收纳方式有什么问题？
- 功能演示：如何打开、清洁和收纳？
- 方案对比：不同解决方案有什么差异？
- 制造过程：产品如何从概念变成样品？
- 使用场景：家庭、办公室、旅行等。
- 设计过程：颜色、造型和包装如何选择？

需要关注的不是只有播放量，还包括：

- 完播率和有效观看
- 点击率
- 收藏、评论和具体问题
- 邮箱、预订或购买意向
- 广告获客成本
- 退款、退货和复购

## 10. 面向欧洲开展 OBM 的责任

如果工厂自己成为品牌方和卖家，需要承担更完整的产品、消费者和渠道责任。

至少应关注：

- 食品接触材料安全与适用测试。
- 一般产品安全、追溯和线上销售责任。
- 平台对商业卖家身份与商品信息的要求。
- 消费者数据、邮箱与营销活动的数据保护。
- 广告、网红和短视频内容中的消费者保护与知识产权。

本课程不是法律意见。正式进入市场前，应由合格的法规、检测和法律专业人员确认具体要求。

## 11. 适合制造工厂的双轨策略

### 主业务：升级 ODM/OEM

- 使用市场分析主动发现客户机会。
- 提供产品概念和系列建议。
- 使用 AI 提升研究、沟通和复盘效率。
- 建立更强的产品开发、质量证据与合规能力。

### 实验业务：小规模 OBM

- 选择容易展示、运输和验证的低风险产品。
- 使用短视频测试消费者兴趣和表达角度。
- 先验证需求，再投入模具和库存。
- 将消费者反馈反向用于 ODM 客户开发。

OBM 实验即使没有立即成为成熟品牌，也能产生消费者数据、产品反馈、内容素材、趋势理解和 ODM 销售案例。
