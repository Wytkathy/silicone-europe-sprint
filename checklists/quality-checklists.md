# Quality Checklists

## Research

- [ ] Every account has an official source URL.
- [ ] Facts and opportunity hypotheses are clearly separated.
- [ ] Sources were re-checked immediately before outreach.
- [ ] Unknown buyer names or sourcing practices are not guessed.
- [ ] Account score can be explained using evidence.

## Outreach

- [ ] Opening observation is accurate and relevant.
- [ ] Email contains no invented need, certification, or capability.
- [ ] Message offers a useful idea or question, not generic praise.
- [ ] CTA is small and appropriate.
- [ ] Recipient and lawful outreach basis have been reviewed.

## Figma

- [ ] Desktop and mobile frames exist.
- [ ] Auto Layout controls related content.
- [ ] Colors, typography, spacing, buttons, and cards are consistent.
- [ ] Visual hierarchy supports the intended buyer journey.
- [ ] Design decisions can be explained from the ICP.

## Website

- [ ] Semantic headings follow a logical order.
- [ ] Buttons and navigation work with keyboard input.
- [ ] Layout works at 360px, 768px, 1024px, and 1440px widths.
- [ ] Text remains readable without horizontal scrolling.
- [ ] Page title, description, and visible CTA are clear.
- [ ] No unverified capabilities or certifications are presented as facts.
- [ ] Forms clearly state that they are demos and do not submit data.

## Final Review

- [ ] `npm run typecheck`
- [ ] `npm test`
- [ ] `npm run build`
- [ ] Compare implementation with Figma.
- [ ] Record what changed after testing.
