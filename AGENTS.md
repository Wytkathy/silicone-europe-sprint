# Project Instructions

## Purpose

This is a coached learning project for European B2B market development, Figma,
and responsive web development. Explain meaningful changes so a beginner can
understand them.

## Commands

- `npm run build`: validate and copy the static site into `dist/`
- `npm run typecheck`: check JavaScript syntax
- `npm test`: run focused site-content tests
- `npm run dev`: serve the project at `http://localhost:4173/site/`

## Content Safety

- Never present fictional factory capabilities, certifications, customers, or
  product claims as verified facts.
- Keep customer research tied to a public source URL.
- Label inferred commercial opportunities as hypotheses.
- Do not send outreach or collect real form submissions.

## Code Style

- Use ES modules and destructured imports where applicable.
- Prefer semantic HTML, accessible controls, and responsive CSS.
- Reuse shared design tokens from `site/styles.css`.

## Definition of Done

- Run `npm run typecheck`, the most relevant focused test, and `npm run build`.
- Verify both pages at desktop and mobile widths.
- Explain important changes in plain language.
